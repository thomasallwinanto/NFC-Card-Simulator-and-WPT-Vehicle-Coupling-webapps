# NFC Card Simulator and WPT Vehicle Coupling Web Apps

Self-contained, single-file web apps. No build step or server needed: open the HTML file in a browser.

| File | What it does |
|---|---|
| `card_simulator_A3.html` | 3D simulator of an NFC card in the field of antenna A3 (CLRC663), bench-calibrated at 5 V / 3.3 V TVDD |
| `WPT_Explorer.html` | Wireless power transfer explorer with three tabs: **Coupling & Efficiency**, **Compensation Topology** (SS/SP/PS/PP) and **VNA S-Parameters** |

Link straight to a WPT tab with a hash: `WPT_Explorer.html#coupling`, `#compensation` or `#vna`.
